# 🛒 Sistema de Controle de Estoque de Mercado

Projeto prático desenvolvido em Java para consolidar fundamentos de lógica de programação, manipulação de arrays e estruturas de repetição.

## 📋 Sobre o Projeto

O sistema simula o módulo de conferência de um pequeno mercado, processando listas de mercadorias para gerar relatórios automatizados de saúde do estoque.

**Funcionalidades:**
- **Cálculo de Patrimônio**: soma automaticamente o valor total investido em mercadorias
- **Alerta de Reposição**: identifica e avisa quais produtos estão com estoque crítico (menos de 10 unidades)
- **Análise de Preços**: identifica o produto de maior valor unitário no catálogo

## 📊 Exemplo de Saída

=== RELATÓRIO DE ESTOQUE ===
Patrimônio total: R$ 15.430,00
⚠️ Estoque crítico: Arroz (8 un), Feijão (5 un)
💎 Produto mais valioso: Azeite Extra Virgem (R$ 45,90)

## 🛠️ Tecnologias e Conceitos

- **Linguagem**: Java
- **Estrutura de dados**: arrays paralelos para armazenar nome, preço e quantidade dos produtos
- **Conceitos**: laços de repetição (`for`), estruturas condicionais (`if/else`), manipulação de arrays

## 🚀 Como Executar

javac Main.java
java Main

## 💡 Aprendizados

Esse projeto ajudou a consolidar como percorrer arrays paralelos e aplicar lógica condicional sobre dados reais, simulando um cenário prático de uso.
