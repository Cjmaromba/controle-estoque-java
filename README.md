# controle-estoque-java
# 🛒 Sistema de Controle de Estoque de Mercado

Este é um projeto prático desenvolvido em **Java** para consolidar fundamentos de lógica de programação, manipulação de arrays e estruturas de repetição.

## 📋 Sobre o Projeto
O sistema simula o módulo de conferência de um pequeno mercado. Ele processa listas de mercadorias para gerar relatórios automatizados de saúde do estoque.

### Funcionalidades:
- **Cálculo de Patrimônio:** Calcula automaticamente o valor total investido em mercadorias.
- **Alerta de Reposição:** Identifica e avisa na tela quais produtos estão com estoque crítico (menos de 10 unidades).
- **Análise de Preços:** Identifica o produto de maior valor unitário no catálogo.

## 🛠️ Tecnologias Utilizadas
- **Linguagem:** Java
- **Conceitos:** Arrays (Vetores), Laços de Repetição (`for`), Estruturas Condicionais (`if/else`).

## 🚀 Como Executar
1. Certifique-se de ter o Java JDK instalado na sua máquina ou utilize o aplicativo **JVdroid** no Android.
2. Copie o código do arquivo `Main.java`.
3. Compile e execute o projeto.
